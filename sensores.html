01 · Conceito

O que é sensoriamento?

Sensoriamento é o processo de captar grandezas físicas ou químicas do ambiente — temperatura, luminosidade, distância, gases, vibração — e convertê-las em sinais elétricos que um microcontrolador ou CLP consegue interpretar. É a "porta de entrada" de qualquer sistema de automação ou IoT: sem sensor, não há dado; sem dado, não há decisão automática.

GRANDEZA FÍSICA

Captação

O elemento sensível reage a uma variação física (calor, luz, pressão, campo magnético) mudando alguma propriedade elétrica sua.

SINAL ELÉTRICO

Conversão

Essa variação vira um sinal — analógico (tensão contínua) ou digital (pulsos, protocolos como I2C, SPI, UART) — pronto para leitura.

PROCESSAMENTO

Interpretação

Um microcontrolador (Arduino, ESP32), Raspberry Pi ou CLP lê o sinal, aplica calibração e transforma em uma medida com significado (°C, %, cm).

AÇÃO

Controle

Com base na leitura, o sistema toma uma decisão: liga um atuador, envia um alerta, publica o dado na nuvem ou ajusta um processo.

02 · Automação Industrial

Sensores, comunicação de dados e controle de processos

Na Indústria 4.0, o sensor deixou de ser um componente isolado: ele é o primeiro elo de uma cadeia que leva o dado do chão de fábrica até a nuvem e de volta, na forma de decisão automática.

Camada 1

Sensoriamento de campo

Sensores de temperatura, presença, gás, vibração, nível e corrente monitoram continuamente o processo físico e alimentam o sistema com dados brutos em tempo real.

Camada 2

Aquisição e comunicação

Microcontroladores (Arduino, ESP32) e CLPs leem os sinais analógicos/digitais e os transmitem via Wi-Fi, protocolos industriais (Modbus, RS-485) ou barramentos locais (I2C, SPI).

Camada 3

Processamento e nuvem

Plataformas de IoT (MQTT, dashboards, bancos de dados em nuvem) armazenam o histórico, geram alertas e permitem análise e visualização remota.

Camada 4

Controle e atuação

Com base nos dados, atuadores (motores, válvulas, relés) corrigem o processo automaticamente — fechando o ciclo sensor → dado → decisão → ação.

03 · Plataforma

Arduino: conceito, funcionamento e programação

O Arduino é a plataforma mais usada para prototipar projetos de sensoriamento — hardware aberto, baixo custo e uma linguagem de programação simplificada (baseada em C/C++).

Conceito e características

O que é o Arduino?

Arduino é uma plataforma de prototipagem eletrônica de hardware livre, composta por uma placa com um microcontrolador (normalmente o ATmega328P, no caso do Uno) e por um ambiente de desenvolvimento (IDE) onde o código é escrito, compilado e enviado à placa via USB.

Cada placa expõe pinos digitais (entrada/saída HIGH ou LOW) e pinos analógicos (leitura de tensão convertida em um valor de 0 a 1023 pelo conversor A/D de 10 bits), além de barramentos I2C e SPI para sensores mais avançados.

01 Características (Arduino Uno R3)

  • Microcontrolador ATmega328P, 16 MHz
  • 14 pinos digitais I/O (6 com saída PWM)
  • 6 entradas analógicas, conversor A/D de 10 bits
  • Alimentação via USB (5 V) ou jack externo (7–12 V)
  • 32 KB de memória flash, 2 KB de SRAM, 1 KB de EEPROM
  • Suporte nativo a I2C (pinos A4/A5) e SPI (pinos 10–13)

02 Funcionamento e programação

  • Código escrito em "sketches" (.ino), estruturados em setup() e loop()
  • setup() roda uma vez: configura pinos e comunicação serial
  • loop() roda continuamente: lê sensores e decide ações
  • Leitura digital: digitalRead() / digitalWrite()
  • Leitura analógica: analogRead() (0–1023)
  • Bibliotecas prontas (Wire, SPI, DHT, HX711 etc.) simplificam sensores complexos

Exemplos de programação — no mínimo 10 sensores

Abaixo, um sketch de exemplo para cada um dos sensores mais representativos do catálogo, cobrindo os principais tipos de sinal (digital, analógico, pulso/interrupção e protocolos I2C/SPI).

01 DHT11 — Temperatura e Umidade (digital 1-fio)

#include <DHT.h>

#define DHTPIN 2        // pino digital conectado ao DHT11
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();          // inicializa o sensor
}

void loop() {
  float umidade = dht.readHumidity();
  float temperatura = dht.readTemperature();

  if (isnan(umidade) || isnan(temperatura)) {
    Serial.println("Falha na leitura do DHT11!");
  } else {
    Serial.print("Umidade: ");   Serial.print(umidade);    Serial.print(" %  ");
    Serial.print("Temperatura: "); Serial.print(temperatura); Serial.println(" *C");
  }
  delay(2000); // DHT11 exige intervalo mínimo entre leituras
}

02 LM35 — Temperatura (analógico)

const int pinoLM35 = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int leitura = analogRead(pinoLM35);           // 0 a 1023
  float tensao = leitura * (5.0 / 1023.0);       // converte para volts
  float temperatura = tensao * 100.0;            // LM35: 10 mV por °C

  Serial.print("Temperatura: ");
  Serial.print(temperatura);
  Serial.println(" *C");
  delay(1000);
}

03 HC-SR04 — Distância (digital, medição de tempo de pulso)

const int trigPin = 9;
const int echoPin = 10;

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);   // pulso de disparo de 10 us
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duracao = pulseIn(echoPin, HIGH);      // tempo do eco em microssegundos
  float distanciaCm = duracao * 0.0343 / 2;   // velocidade do som / 2

  Serial.print("Distancia: ");
  Serial.print(distanciaCm);
  Serial.println(" cm");
  delay(300);
}

04 PIR HC-SR501 — Presença (digital)

const int pinoPIR = 3;
const int pinoLED = 13;

void setup() {
  Serial.begin(9600);
  pinMode(pinoPIR, INPUT);
  pinMode(pinoLED, OUTPUT);
}

void loop() {
  int movimento = digitalRead(pinoPIR);

  if (movimento == HIGH) {
    digitalWrite(pinoLED, HIGH);
    Serial.println("Movimento detectado!");
  } else {
    digitalWrite(pinoLED, LOW);
  }
  delay(200);
}

05 LDR — Luminosidade (analógico)

const int pinoLDR = A0;
const int limiar = 400; // ajuste conforme o ambiente

void setup() {
  Serial.begin(9600);
  pinMode(13, OUTPUT); // LED indicador
}

void loop() {
  int luz = analogRead(pinoLDR); // 0 (escuro) a 1023 (muito claro)
  Serial.print("Nivel de luz: ");
  Serial.println(luz);

  if (luz < limiar) {
    digitalWrite(13, HIGH); // escureceu: liga iluminação
  } else {
    digitalWrite(13, LOW);
  }
  delay(500);
}

06 MQ-2 — Gás/Fumaça (analógico + digital)

const int pinoAnalogico = A0;
const int pinoDigital   = 7;

void setup() {
  Serial.begin(9600);
  pinMode(pinoDigital, INPUT);
}

void loop() {
  int nivelGas = analogRead(pinoAnalogico);   // concentração relativa
  int alarme   = digitalRead(pinoDigital);    // 1 = acima do limiar ajustado

  Serial.print("Nivel de gas: "); Serial.print(nivelGas);
  Serial.print(" | Alarme: ");    Serial.println(alarme == HIGH ? "SIM" : "nao");

  if (alarme == HIGH) {
    Serial.println(">>> Risco de vazamento detectado!");
  }
  delay(1000);
}

07 Sensor Capacitivo de Umidade do Solo (analógico)

const int pinoSensor = A0;
const int pinoBomba   = 8;
const int limiarSeco  = 600; // calibrar conforme o solo/sensor

void setup() {
  Serial.begin(9600);
  pinMode(pinoBomba, OUTPUT);
}

void loop() {
  int umidadeSolo = analogRead(pinoSensor); // valores menores = solo mais úmido

  Serial.print("Umidade do solo (raw): ");
  Serial.println(umidadeSolo);

  if (umidadeSolo > limiarSeco) {
    digitalWrite(pinoBomba, HIGH); // solo seco: liga irrigação
    delay(5000);
    digitalWrite(pinoBomba, LOW);
  }
  delay(2000);
}

08 YF-S201 — Fluxo de Água (digital, pulsos por interrupção)

volatile long pulsos = 0;
const int pinoSensor = 2; // precisa ser um pino com suporte a interrupção

void contaPulso() {
  pulsos++;
}

void setup() {
  Serial.begin(9600);
  pinMode(pinoSensor, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(pinoSensor), contaPulso, RISING);
}

void loop() {
  pulsos = 0;
  sei();
  delay(1000);           // conta pulsos durante 1 segundo
  cli();
  float litrosPorMinuto = (pulsos / 4.5); // ~4.5 pulsos por litro (YF-S201)

  Serial.print("Vazao: ");
  Serial.print(litrosPorMinuto);
  Serial.println(" L/min");
}

09 MFRC522 — Leitor RFID (digital, SPI)

#include <SPI.h>
#include <MFRC522.h>

#define SS_PIN  10
#define RST_PIN 9
MFRC522 leitor(SS_PIN, RST_PIN);

void setup() {
  Serial.begin(9600);
  SPI.begin();
  leitor.PCD_Init();
  Serial.println("Aproxime um cartao RFID...");
}

void loop() {
  if (!leitor.PICC_IsNewCardPresent() || !leitor.PICC_ReadCardSerial()) {
    return;
  }

  Serial.print("UID do cartao: ");
  for (byte i = 0; i < leitor.uid.size; i++) {
    Serial.print(leitor.uid.uidByte[i] < 0x10 ? " 0" : " ");
    Serial.print(leitor.uid.uidByte[i], HEX);
  }
  Serial.println();
  leitor.PICC_HaltA();
}

10 Célula de Carga + HX711 — Peso (digital, protocolo síncrono)

#include "HX711.h"

const int pinoDT  = 4;
const int pinoSCK = 5;
HX711 balanca;

void setup() {
  Serial.begin(9600);
  balanca.begin(pinoDT, pinoSCK);
  balanca.set_scale(2280.f);  // fator de calibração (obtido com peso conhecido)
  balanca.tare();             // zera a balança sem peso sobre a célula
}

void loop() {
  float peso = balanca.get_units(10); // média de 10 leituras, em gramas/kg
  Serial.print("Peso: ");
  Serial.print(peso);
  Serial.println(" kg");
  delay(500);
}

DHT11

Sensor digital combinado de temperatura e umidade relativa do ar, muito usado em projetos educacionais e de baixo custo.

01 Princípio de funcionamento

Um termistor NTC mede a temperatura e um sensor capacitivo de umidade mede a variação de capacitância conforme a umidade do ar; um chip interno faz a conversão e envia os dois valores por um único fio.

02 Especificações técnicas

  • Tensão: 3 a 5,5 V
  • Umidade: 20–90% (±5%)
  • Temperatura: 0–50 °C (±2 °C)
  • Taxa de amostragem: ~1 Hz

Tipo de sinal: Digital (protocolo proprietário de 1 fio)

Aplicações e exemplo de uso

  • Estações meteorológicas simples
  • Automação residencial (climatização)
  • Projetos educacionais de IoT

Exemplo de projeto: Leitura periódica de temperatura e umidade de uma sala, publicada em um dashboard via ESP32.

Luminosidade

LDR (Fotorresistor)

Resistor sensível à luz (Light Dependent Resistor): sua resistência elétrica varia conforme a quantidade de luz incidente.

01 Princípio de funcionamento

O material semicondutor (geralmente sulfeto de cádmio) libera mais elétrons livres quanto mais luz recebe, diminuindo sua resistência; um divisor de tensão converte essa mudança em um sinal analógico.

02 Especificações técnicas

  • Resistência no escuro: >1 MΩ
  • Resistência sob luz: poucas centenas de Ω
  • Tempo de resposta: dezenas de ms

Tipo de sinal: Analógico (via divisor de tensão)

Aplicações e exemplo de uso

  • Controle automático de iluminação pública
  • Persianas e cortinas automatizadas
  • Detecção de dia/noite em estufas

Exemplo de projeto: Acionamento automático de uma luminária de rua quando o nível de luz ambiente cai abaixo de um limite.

HC-SR04

Sensor ultrassônico de distância, um dos mais populares em robótica e automação por seu baixo custo e boa precisão.

Sensor Indutivo LJ12A3

Sensor de proximidade que detecta objetos metálicos sem contato físico, muito usado em linhas de produção industriais.

Uma bobina interna gera um campo eletromagnético oscilante; a aproximação de um metal induz correntes parasitas que amortecem o campo, e o circuito detecta essa variação como presença de objeto.

02 Especificações técnicas

  • Tensão: 6 a 36 V DC
  • Distância de detecção: até 4 mm (típico)
  • Saída: NPN ou PNP, NA ou NF

Tipo de sinal: Digital (saída a transistor NPN/PNP)

Aplicações e exemplo de uso

  • Contagem de peças metálicas em esteiras
  • Detecção de fim de curso em máquinas
  • Sensoriamento em CLPs industriais

Exemplo de projeto: Contagem de latas metálicas passando em uma esteira transportadora, incrementando um contador a cada pulso.

MQ-2

Sensor semicondutor para detecção de gases combustíveis e fumaça, muito usado em sistemas de segurança contra incêndio e vazamentos.

01 Princípio de funcionamento

Um elemento sensível de dióxido de estanho (SnO₂) reduz sua resistência elétrica na presença dos gases-alvo (GLP, propano, metano, fumaça); o circuito converte essa variação em um sinal de tensão.

02 Especificações técnicas

  • Tensão: 5 V
  • Detecta: GLP, propano, metano, fumaça, álcool
  • Tempo de pré-aquecimento: ~1–2 minutos
  • Saída analógica e digital (com comparador)

Tipo de sinal: Analógico (A0) e Digital (D0, via potenciômetro comparador)

Aplicações e exemplo de uso

  • Detectores de vazamento de gás doméstico e industrial
  • Alarmes de incêndio e fumaça
  • Ventilação automática de ambientes

Exemplo de projeto: Acionamento de um alarme sonoro e de uma válvula solenoide quando a concentração de gás ultrapassa um limite.

Sensor Capacitivo de Umidade do Solo

Mede a umidade do solo sem corrosão do eletrodo, ideal para irrigação automatizada e agricultura inteligente.

01 Princípio de funcionamento

Duas placas capacitivas inseridas no solo formam um capacitor cuja capacitância varia conforme o teor de água no solo (a água aumenta a constante dielétrica do meio).

02 Especificações técnicas

  • Tensão: 3,3 a 5,5 V
  • Saída: analógica (0–3 V aprox.)
  • Material: PCB revestida (não corrosiva, ao contrário dos sensores resistivos)

Tipo de sinal: Analógico

Aplicações e exemplo de uso

  • Irrigação automática de hortas e plantações
  • Agricultura de precisão
  • Monitoramento de vasos inteligentes

Sensor de Chuva FC-37

Detecta a presença e intensidade de chuva através de uma placa com trilhas condutoras expostas.

01 Princípio de funcionamento

Gotas de água sobre a placa formam pequenas pontes condutoras entre as trilhas, reduzindo a resistência medida; quanto mais água, menor a resistência e maior o sinal analógico.

02 Especificações técnicas

  • Saída: analógica e digital (com comparador)

Aplicações e exemplo de uso

  • Fechamento automático de coberturas e toldos
  • Sistemas de irrigação que pausam com chuva
  • Estações meteorológicas residenciais

Exemplo de projeto: Suspensão automática do ciclo de irrigação de um jardim quando o sensor detecta chuva.

Sensor de Nível (Boia)

Interruptor mecânico de nível: uma boia com ímã interno aciona um reed switch conforme sobe ou desce com o líquido.

01 Princípio de funcionamento

A boia flutua sobre a superfície do líquido; ao atingir a posição configurada, o ímã em seu interior aproxima-se do reed switch, fechando (ou abrindo) o contato elétrico.

02 Especificações técnicas

  • Saída: contato seco (NA ou NF)

Tipo de sinal: Digital (contato seco, tipo chave)

Aplicações e exemplo de uso

  • Controle de nível em caixas d'água e reservatórios
  • Proteção contra funcionamento a seco de bombas
  • Alarme de transbordamento

Exemplo de projeto: Acionamento automático de uma bomba de recalque quando o nível da caixa d'água atinge a boia inferior.

  • Controle de dosagem em processos
  • Detecção de vazamentos por consumo anômalo

  • Interfaces de usuário (ajuste de valores, menus)
  • Contadores de rotação de baixo custo

Célula de Carga + HX711

Conjunto para medição de peso: a célula de carga deforma-se sob peso e o módulo HX711 amplifica e digitaliza o sinal.

01 Princípio de funcionamento

A célula de carga contém extensômetros (strain gauges) que mudam de resistência ao se deformar sob peso; o HX711 é um conversor A/D de 24 bits dedicado a amplificar esse sinal muito pequeno com alta precisão.

02 Especificações técnicas

  • Tensão HX711: 2,6 a 5,5 V
  • Resolução: 24 bits
  • Capacidade da célula: varia por modelo (1 kg a várias toneladas)

Tipo de sinal: Digital (protocolo síncrono proprietário do HX711, 2 fios)

Aplicações e exemplo de uso

  • Balanças industriais e comerciais
  • Sistemas de pesagem em silos e esteiras
  • Controle de dosagem por peso

Exemplo de projeto: Leitura contínua do peso em uma balança industrial via biblioteca HX711, calibrada com um peso de referência conhecido.

Sensor de Chama IR

Detecta a radiação infravermelha característica de chamas, permitindo identificar princípios de incêndio rapidamente.

01 Princípio de funcionamento

Um fotodiodo sensível à faixa infravermelha (760–1100 nm, espectro emitido pelo fogo) capta a radiação da chama; o circuito compara a intensidade captada com um limiar para indicar presença de fogo.

02 Especificações técnicas

  • Tensão: 3,3 a 5 V
  • Ângulo de detecção: ~60°
  • Alcance: cerca de 1 m (varia com o tamanho da chama)
  • Saída: analógica e digital

Tipo de sinal: Analógico (A0) e Digital (D0, via potenciômetro comparador)

Aplicações e exemplo de uso

  • Sistemas de detecção precoce de incêndio
  • Robótica de combate a incêndio (robôs apaga-vela)
  • Monitoramento de fornos e caldeiras

Exemplo de projeto: Disparo de um alarme sonoro e de uma notificação IoT assim que o sensor detecta a presença de chama.
